# Neon Drift

A small browser game prototype built with HTML, CSS, and vanilla JavaScript.

## Goal

Collect energy cores, avoid drones, and finish before the timer expires.

## Run locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- Move: WASD or Arrow keys
- Objective: Collect 8 cores before time runs out

## Files

- `index.html` - page structure
- `style.css` - UI and layout
- `game.js` - gameplay logic
